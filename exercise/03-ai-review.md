# งานที่ 3: ให้ AI รีวิว ADR (ประมาณ 5 นาที)

> **เชื่อมโยงกับการบรรยาย:** P5 การทำงานร่วมกันระหว่างมนุษย์กับ AI โดย AI รับบทเป็น *Chief Analyst* งานวิจัยปี 2026 พบว่า LLM มักทำได้เท่าหรือดีกว่าทีมนักศึกษาในการหาความเสี่ยงและ trade-off แบบ ATAM ([arXiv 2603.28914](https://arxiv.org/abs/2603.28914)) ส่วน B จะทดสอบข้ออ้างนี้

เริ่มแชตหรือ session ใหม่ แล้วส่งข้อความด้านล่าง โดยใส่ path ของ **ADR ฉบับสุดท้ายของนิสิต**

```
Follow prompts/3-review-adr.md
adr: docs/adr/0002-<your-title>.md
language: Thai
```

บรรทัด `language: Thai` ทำให้ผลรีวิวเป็นภาษาไทย (ประเภทของข้อค้นพบ เช่น Risk, Trade-off point ยังคงเป็นภาษาอังกฤษ) หากต้องการภาษาอังกฤษให้ลบบรรทัดนี้

agent จะเขียนผลรีวิวแบบ ATAM ความยาวหนึ่งหน้าไว้ที่ [`outputs/3-review.md`](outputs/3-review.md) agent ต้องไม่แก้ไข ADR ของนิสิต หากแก้ไข ให้ปฏิเสธหรือ undo การเปลี่ยนแปลงนั้น

**ยังไม่ต้องแก้ไขตามผลรีวิว** ให้อ่าน commit และนำไปใช้ในที่ประชุมคณะกรรมการรีวิวในส่วน B คณะกรรมการจะเป็นผู้ตัดสินว่าข้อค้นพบใดสำคัญ

- **ความประทับใจแรกต่อผลรีวิวของ AI** (หนึ่งประโยค): ข้อค้นพบเรื่องแต้มภายในหนึ่งนาทีขัดกับ availability เมื่อ loyalty ล่มนานมีประโยชน์ที่สุด ส่วนที่ยังอ่อนคือยังประเมินภาระดูแลทีม 4 คนไม่ได้จากข้อมูลจริง

## สถานะผลรีวิวล่าสุด

- **วันที่รีวิว:** 2026-10-27
- **เป้าหมาย:** [ADR-0002](../docs/adr/0002-use-rabbitmq-for-post-order-actions.md)
- **กระบวนการ:** สร้างแชตใหม่สำหรับงาน 3 โดยไม่ส่งประวัติแชตเดิมหรือผลรีวิวก่อนหน้า แชตรีวิวคือ `01a17df0-16b6-7403-9ae1-119da2873cfb`
- **ไฟล์ที่ผู้รีวิวรายงานว่าอ่านทั้งหมด:** `AGENTS.md`, `prompts/3-review-adr.md`, `docs/scenario.md` และ `docs/adr/0002-use-rabbitmq-for-post-order-actions.md` ไม่อ่านใบงาน ผลลัพธ์เดิม หรือ application source เป็นหลักฐาน
- **ผลรีวิว:** [outputs/3-review.md](outputs/3-review.md) — `accept with changes`
- **ฉบับที่ตรวจจริง:** [adr-reviewed-snapshot.md](outputs/adr-reviewed-snapshot.md) เป็นสำเนาตรงกับ ADR ที่ reviewer อ่าน เลขบรรทัดในรีวิวอ้างฉบับนี้ หลังรีวิวอัปเดตเฉพาะบันทึกมติที่ผู้ใช้ยืนยัน
- **มติหลังเห็นผลรีวิวใหม่:** ผู้ใช้ยืนยันคง Option 3 พร้อมเงื่อนไขทั้งสาม: รับรองนิยาม SLA แต้ม, ระบุความจุ/ผู้ดูแล/การกู้คืน และเก็บหลักฐานทดสอบก่อนใช้งานจริง บันทึกในใบงาน 04 และ ADR
- **ลำดับเหตุการณ์:** รีวิวอิสระนี้ทำหลังผู้ใช้แจ้งผลประชุมเดิม แล้วผู้ใช้ยืนยันมติพร้อมเงื่อนไขอีกครั้งหลังเห็นผลรีวิวใหม่ ไม่ย้อนไปอ้างว่ารอบใหม่นี้เกิดก่อนประชุมเดิม
- **ประวัติ:** รีวิวร่วมแชตก่อนหน้าเก็บใน [3-review-before-independent.md](outputs/3-review-before-independent.md); รีวิวเบื้องต้นของร่าง 2b เก็บใน [3-review-preliminary.md](outputs/3-review-preliminary.md)
- **ผลทดสอบ:** ยังไม่ได้รันระบบจริง การมีรีวิวและมติไม่ใช่ผลว่าระบบผ่าน SLA แล้ว
